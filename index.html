Features

Cloud storage, but with a brain.

Three capabilities that make Aether Cosmos different from every other self-hosted cloud. Concrete, measured, shipped.

Private-R2 video playback.
Zero proxy overhead.

Direct byte-range streaming from Cloudflare R2. No VPS proxy, no transcoding bottleneck. The control plane authenticates; the data plane streams straight from the bucket. Encrypted at rest, signed URLs with a 2-hour window.

Second Brain

Memory that outlives the conversation.

Most agents start from zero every session. Aether Cosmos gives yours persistent, user-owned memory — accessible over MCP from any client.

  • Versioned memories

    Nothing is ever lost. Every fact carries its source and timestamp. Diff and roll back like Git for thoughts.

  • Knowledge graph

    Visualize how concepts, people, and projects connect across time. Edges are first-class — query them like data.

  • Hybrid retrieval

    Keyword + semantic search over the entire memory corpus. Sub-100ms recall for thousands of facts.

  • MCP server

    Connect Claude, Cursor, Cline, or any MCP-aware agent over HTTP. Standard protocol, zero glue code.
