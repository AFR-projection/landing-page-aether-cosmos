Features

Everything you'd expect.
Plus a brain.

Cloud storage that doesn't just hold files — it remembers what they mean and what your agents did with them.

Upload anything

Single files, whole folders, drag-and-drop, version history, recycle bin, and full-text search across everything.

End-to-end encryption

Optional E2EE where the server never sees the passphrase. Your data, your keys, your sovereignty.

Auth done right

Argon2id sessions, TOTP 2FA, a numeric second step, email OTP, and per-user quotas out of the box.

Sharing & previews

Share links with audit trails, in-browser previews for documents, images, video, and audio — no third-party viewer.

Admin & analytics

User management, impersonation for support, share auditing, storage analytics, activity logs, platform settings.

Backup & restore

One encrypted .afrbak per account, with a nine-word recovery phrase. Restore into any Aether Cosmos install.

Second Brain

Memory that outlives
the conversation.

Most AI agents start from zero every session. Aether Cosmos gives yours a persistent, user-owned memory: versioned facts, an interactive knowledge graph, and hybrid retrieval — accessible from any agent over the MCP protocol.

  • Versioned memories — trace any fact back to its source.
  • Knowledge graph — visualize how concepts, people, and projects connect across time.
  • Hybrid retrieval — keyword + semantic search over the entire memory corpus.
  • MCP server — connect Claude, Cursor, Cline, or any MCP-aware agent over HTTP.

Deploy

One command on a fresh VPS.

Installs Docker, clones the repo, opens the .env for you to fill in, issues the certificate, builds, and health-checks.

bash
$ curl -fsSL https://raw.githubusercontent.com/AFR-projection/Aether-Cosmos/main/scripts/deploy/setup.sh | bash

Afterwards, manage everything with aether: update, status, logs.
