01 — Capabilities

Everything you'd expect.
Plus a brain.

Cloud storage that doesn't just hold files — it remembers what they mean and what your agents did with them. Six capabilities, one cohesive system.

01 / 06 Storage

Upload, version, and search anything.

Whole folders. Drag-and-drop. Version history. Recycle bin. Full-text search across every file — even inside E2EE blobs, if you hold the key.

02 / 06 Security

E2EE by default.

Server never sees your passphrase.

03 / 06 Auth

Argon2id + TOTP + numeric step.

Email OTP, per-user quotas, lockout policies.

04 / 06 Share

Links with audit trails.

Documents, images, video, audio — previewed in-browser. Every share, every view, logged.

05 / 06 Admin

One console. Every signal.

Users, impersonation, audits, storage analytics, activity, settings — all live, all queryable.

06 / 06 Backup

One encrypted .afrbak per account. Nine words to restore anywhere.

Export your files and your Second Brain as a single archive, encrypted, with a recovery phrase that works on any Aether Cosmos install. Disaster recovery, simplified.

02 — Second Brain

Memory that outlives the conversation.

Most agents start from zero every session. Aether Cosmos gives yours a persistent, user-owned memory — accessible over MCP from any client.

  • 01

    Versioned memories

    Nothing is ever lost. Every fact carries its source and timestamp. Diff and roll back like Git for thoughts.

  • 02

    Knowledge graph

    Visualize how concepts, people, and projects connect across time. Edges are first-class — query them like data.

  • 03

    Hybrid retrieval

    Keyword + semantic search over the entire memory corpus. Sub-100ms recall for thousands of facts.

  • 04

    MCP server

    Connect Claude, Cursor, Cline, or any MCP-aware agent over HTTP. Standard protocol, zero glue code.

03 — The stack

Boring on purpose.

Every dependency is one you can hire for. Nothing exotic, nothing you can't self-host on a $5 VPS.

01 Framework App Router, React Server Components Next.js 16.3
02 Language strict, modern TypeScript 5
03 Database Postgres 16, full-text search built in PostgreSQL + Drizzle
04 Object storage S3-compatible, no egress fees Cloudflare R2
05 Cache & queue Background workers, retries, scheduling Redis + BullMQ
06 UI Accessible primitives, motion-friendly Tailwind v4 + Radix
07 Deployment One command, zero-downtime updates Docker + Nginx + Certbot
