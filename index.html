Features

Persistent, user-owned memory for AI agents. Versioned memories, an interactive knowledge graph, and hybrid retrieval.

  • →Interactive knowledge graph with full CRUD
  • →MCP server agents connect to over HTTP

Secure Files

R2-backed object storage with folder uploads, versions, recycle bin, and ranked search.

  • →End-to-end encryption, AES-GCM in-browser

Architecture

One deploy. Three stores. Zero lock-in.

A single Next.js app behind Nginx, talking to Cloudflare R2 for objects, PostgreSQL for metadata and memory, and Redis for queues — plus an MCP server agents connect to over HTTP.

Deploy

Live today. Yours tomorrow.

The instance at mindvault.dataku.id runs this exact build in production. Spin up your own on any Ubuntu VPS with one command — installs Docker, issues the certificate, builds, and health-checks.

Open the live app Read deployment docs
aether — one command deploy 
$ curl -fsSL https://raw.githubusercontent.com/AFR-projection/Aether-Cosmos/main/scripts/deploy/setup.sh | bash
# installs Docker · clones · opens .env
# issues TLS · builds · health-checks
$ aether update     # pull · rebuild · sync · renew
$ aether status     # health of every service
$ aether logs app   # follow logs
